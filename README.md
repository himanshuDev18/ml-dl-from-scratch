
# Machine Learning and Deep Learning from Scratch

A learning-oriented repository focused on understanding machine learning and deep learning through mathematical foundations, conceptual explanations, implementations from scratch, and practical experimentation.

The goal is to understand not only how algorithms are used, but also how they work internally and how their mathematical foundations translate into code.

## Objectives

- Build a strong mathematical foundation for machine learning and deep learning.
- Understand the intuition and working principles behind different algorithms.
- Study mathematical derivations and connect them with practical implementations.
- Implement algorithms from scratch to understand their internal mechanisms.
- Experiment with data and analyze model behavior and performance.
- Develop practical programming and problem-solving skills through hands-on learning.

## Topics

The repository covers concepts related to machine learning, deep learning, mathematics, optimization, and computational methods.

Topics are organized into directories as the repository grows. Each topic may include conceptual explanations, mathematical derivations, implementations, visualizations, experiments, and results.

### Deep Learning

- [Perceptron and Gradient Descent](deep-learning/perceptron/README.md) — Mathematical foundations, implementation, and experimental results.

## Technologies

This repository uses Python and its ecosystem for numerical computation, algorithm implementation, visualization, and experimentation.

Tools and libraries are selected according to the requirements of each topic and experiment.

## Learning Approach

Each topic follows a concept-to-implementation approach:

1. Understand the problem and its underlying intuition.
2. Study the relevant mathematical foundations.
3. Derive the equations and principles required for implementation.
4. Implement the concepts and algorithms from scratch where appropriate.
5. Conduct experiments and visualize results when useful.
6. Evaluate performance and analyze observations.

## Repository Structure

The repository is organized into topic-wise directories containing relevant implementations, notebooks, explanations, and experiments.

Each directory may include its own README to document the concepts, implementation details, assumptions, results, and conclusions specific to that topic.

## Progress

This repository is continuously evolving as new concepts are explored, implementations are added, and existing work is refined.

## Purpose

The ultimate goal is to develop a deeper understanding of machine learning and deep learning by connecting theory, mathematics, programming, and experimentation, rather than relying solely on existing implementations.
